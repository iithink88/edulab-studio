# edulab 一键课件工作台

把学科题目变成**可交互的教学网页**和**带中文配音的讲解视频**的桌面小工具。
左侧按学科选技能 → 输入题目（文字或图片）→ 点「一键生成」→ 网页直接预览 / MP4 直接播放。

基于已安装的 6 个 edulab 技能（立体几何 / 解析几何 / 化学 / 数学 / 物理），本工作台负责：
题目图片 OCR、题型判定、解题规划、分镜与动画生成、配音、逐帧渲染的**全流程编排**。

---

## 一、安装（3 步）

**第 1 步：放置技能**
把本包 `skills/` 里的 6 个 `edu-` 文件夹复制到技能目录（二选一，已存在则跳过）：

- Windows：`C:\Users\<你的用户名>\.workbuddy\skills\`
- 或直接放在本程序同级目录的 `skills\` 文件夹里（随包分发模式）

**第 2 步：装依赖**（本机已装可跳过）

```bash
# Python（用一个带以下包的解释器运行本程序）
python -m pip install sympy numpy requests pypinyin pillow edge-tts

# Node（视频渲染用，在本程序目录执行一次）
npm install playwright@1.49 ffmpeg-static
npx playwright install chromium     # 没有 Google Chrome 时才需要
```

**第 3 步：配置 Key**（可选但推荐）

把 `config.example.json` 复制为 `config.json`，填入：

| 配置 | 用途 | 不填会怎样 |
|---|---|---|
| `dashscope_key` | 阿里云百炼 Key：图片 OCR、题目理解、分镜/动画生成 | **自定义题目不可用**（预设题库仍可用） |
| `glm_key` | 智谱 GLM-TTS Key（配音音质更佳） | 自动用 edge-tts 免费配音（需联网） |

Key 只保存在本机 `config.json`，不要外发。

## 二、启动

双击 **`启动工作台.bat`**（或 `python edulab_studio.py`），浏览器会自动打开工作台。

## 三、使用

1. **左侧选技能**（按学科分组：数学 / 立体几何 / 化学 / 物理）
2. **输入题目**：
   - 「手动输入」：直接打字
   - 「上传图片」：拖入或选择题目截图，点「识别图中文字」自动转文字
3. **点「一键生成」**：实时日志显示每个阶段；完成后在「生成结果」里：
   - 网页课件 → 「网页预览」内嵌打开 / 下载
   - 讲解视频 → 内嵌播放 / 下载 MP4 + SRT 字幕

### 各技能产出

| 技能 | 输入示例 | 产出 |
|---|---|---|
| 立体几何交互课件 | 「正四棱锥底面边长 4 高 2」 | Three.js 3D 交互解题网页 |
| 解析几何交互课件 | 圆锥曲线题/预设题库 | Canvas 参数滑块交互网页 |
| 化学反应微观演示 | 「氢气燃烧」/自写反应 | 断键成键 3D 分子动画网页 |
| 数学/物理/化学讲解视频 | 任意题目文字或图片 | 1920×1080 MP4（配音+双语字幕+动画） |

### 小贴士

- 网页类「自定义题目」是把题目映射到内核支持的题型（参数随题干变化），问法不同时以最接近的题型出课件；
- 视频生成约 10~20 分钟（规划→检查→试听前预览→配音→逐帧渲染），日志里有每个阶段的耗时；
- 生成的课件在 `输出/` 目录，每个任务一个文件夹；
- 首次用建议先点「预设题库」里的示例，30 秒看到效果。

## 四、目录说明

```
edulab-studio/
├── 启动工作台.bat      双击启动
├── edulab_studio.py    后端（编排 + LLM + HTTP 服务，纯标准库）
├── bridge_web.py       网页技能桥接（sympy 内核 → HTML）
├── static/index.html   前端界面
├── config.json         本机配置（Key，勿外发）
├── skills/             6 个 edulab 技能（随包分发）
├── 输出/               生成结果
└── examples/               本机实测产出的演示成果（含化学演示 MP4 与 SRT 字幕；
                           MP4 约 15MB，发布版未内置，可从桌面分享包
                           「edulab一键课件工作台.zip」中取）
```

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 顶栏「Python 依赖」红灯 | 用带了 sympy/numpy/… 的解释器启动；`启动工作台.bat` 默认找托管 venv |
| 「Node/渲染内核」红灯 | 在程序目录跑 `npm install playwright@1.49 ffmpeg-static` |
| 生成中途报「LLM 接口 …」 | 检查 `config.json` 的百炼 Key 与余额 |
| 配音失败 | edge-tts 需联网；多次重试或配置 `glm_key` 用 GLM-TTS |
| 生成的网页公式不显示 | 页面从公共 CDN 加载 MathJax/KaTeX/Three.js，需联网打开 |

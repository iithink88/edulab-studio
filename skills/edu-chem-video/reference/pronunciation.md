# 读音控制（pron.py + pron.json）

## 为什么需要

GLM-TTS 没有 SSML、拼音或音素输入，多音字和生僻字靠它自己猜，经常读错（"AC长三"会读成 zhǎng，"三角形"偶尔读成 jué）。行内写拼音会被原样念出来。

解决办法：**只在送给 TTS 的文本里，把要固定读音的字换成一个同音同调的常用字**（长 cháng → 常，角 jiǎo → 搅）。字幕仍显示原字。每次替换都记录在 `build/pron_report.txt` 的"固定"行里。

**但替换有代价：会破坏断句。** TTS 先按词切分再决定在哪里停顿，`直搅三搅形`、`蛋气、养气、二养化探` 这种不成词的文本会让它多停、变慢（实测同一句：替换版 4 处停顿、5.9 秒，原文 2 处、5.1 秒）。所以 `pron.py` 按下面的规则决定换不换，不要改回"一律替换"：

| 情况 | 送给 TTS |
|---|---|
| 行内标注 `字[拼音]` | **一律替换**（你明确要求的） |
| 生僻字（不在 3755 个一级常用字里） | 一律替换 |
| `pron.json` 的 `always` 里的字（汞、氦、氖、锰、钾、朔：实测在清楚的上下文里也读错过） | 一律替换 |
| `words` 词表里的词，按词典上下文读法已经是目标读音（`直角三角形`、`平行`、`得到`、`相等`、`延长线`） | **原样发送**，保住词形和断句 |
| `words` 词表里的词，按上下文会读错（`CD的长` 会读成 zhǎng，`分子` 词典默认读 fèn zǐ） | 替换 |

用户说某个原样发送的词读错了：把那个字加进 `always`，或在那句行内标注。

## 三种固定方式

| 方式 | 写法 | 何时用 |
|---|---|---|
| 行内标注 | 在 `tts`（或 `zh`）里，字**后面**加 `[拼音]`：`长[cháng]`、`要[yào]求`、`行[xíng]`；声调可写符号或数字 `长[chang2]` | 只在这句里、依赖上下文的读音 |
| 词表 `words` | `pron.json`（链接到技能的 `shared/pron.json`，所有视频共用一份） → `"words": {"边长": "_ cháng"}`，每个字一个音节，`_` = 这个字不动 | 反复出现的术语，所有视频通用 |
| 确认表 `ok` | `pron.json` → `"ok": ["时间"]` | 你确认 TTS 默认读音就是对的，只是 lint 报了 ⚠ |

**标注只作用于紧挨着的前一个字。** `中点[zhōng]` 是错的（会把"点"读成 zhōng）。

`words` 按词长从长到短匹配，被行内标注过的字不会再被词表改。

## 流程

```bash
cd PROJ && PY build_audio.py --check ; cat build/pron_report.txt
```
报告格式：
```
[figure 0] 先画图：C是直角顶点，AC长三，BC长四。
    固定  角 -> jiao3  (送给TTS: 搅)             ← 已固定，无需处理
    ⚠ 多音  长  猜测读 zhang3  (可能: zhang3/chang2)  …点，AC长三，BC…   ← 必须处理
```
对每个 ⚠：
1. 根据上下文判断正确读音（"AC长三"是长度 → cháng）。
2. 这句专用 → 行内标注 `AC长[cháng]三`。常用术语 → 加进 `words`。确认猜测读音就是对的 → 把**词**（不是单字）加进 `ok`。
3. 重跑 `--check`，直到 `未固定读音的生僻字/多音字: 0`。

注意：`ok` 里放单字会让这个字在所有地方都不再报警，只放词。

## 字母（点名、线段名）

GLM-TTS 会把连在一起的字母当成一个音节读：`CO` 读成"口"，`ACBE` 丢掉 E。**`pron.py` 已自动处理**：送给 TTS 时，两个及以上相邻的字母之间一律加空格（`CO` → `C O`，`ACBE` → `A C B E`），报告里显示为 `固定  CO -> 逐个字母`。字幕不受影响。实测过：语音识别确认加空格后逐个字母读出，测量音频里的静音确认没有多余停顿（不加空格的 `PAB` 会被读成"派"）；顿号或逗号分隔虽然也能读对，但会多出停顿，不要用。

所以 tts 里照常写 `AB`、`△ABC` 对应的 `三角形ABC` 即可，**不要**手动写成 `A、B`。

仍需注意：
- 单个小写字母（`t`、`x`）照写；小写单词（sin、log）要换成中文（`--check` 会 warn），否则会被拆成 s i n 逐个念。
- 字母前面加类别名词更稳：`点T`、`线段CM`、`弧线AC`，句首不要直接以字母开头。
- 生成配音后跑 `PY build_audio.py --asr`：它把每句配音识别成文字，比较字母序列，读错的句子标 ✗。常见原因和处理：字母紧挨着同音汉字被连读 → 在那里加逗号；句子太长 → 拆句。改完重跑 `build_audio.py` 和 `--asr`。
- `--asr` 的识别本身也会出错（已把 T/D、M/N 视为相同）。改写后仍然标 ✗ 的句子（例如 `角PAO` 总被识别成"配欧"），交付时列给用户，请用户重点试听；不要为了消除 ✗ 把句子改得不通顺。

## 化学式、离子、希腊字母（tts 里写中文名称）

- 化学式不能出现在 tts 里（数字会被 `--check` 拦住）：`HNO3` → 硝酸，`SO4^{2-}` → 硫酸根离子。对照表见 script-writing.md。
- 单独的元素符号读中文名：`Cu` → 铜，不要让 TTS 读 "C u"。
- 希腊字母：α 阿尔法（或"转化率"）、Δ 德尔塔（或"变化量"）、ρ 肉（或"密度"）、ω 欧米嘎（或"质量分数"）。

## 用户说某个字读错了

1. 加进 `pron.json` 的 `words`（通用术语），或在那句加行内标注。
2. `PY build_audio.py --check` 确认"固定"行里出现了它。
3. `PY build_audio.py`：音频按送给 TTS 的文本缓存，只有改过的句子会重新合成。
4. 重新渲染视频。
5. 可以先单独试听：`PY build_audio.py --say "铜被氧化，硝酸被还原"`，把生成的 wav 发给用户确认。

## 同音字表 `homophones`

`pron.json` 的 `homophones` 指定某个"拼音+声调"用哪个字替换（如 `"chang2": "常"`）。没指定时 `pron.py` 自动挑一个常用字。自动挑的字本身读音有歧义时才需要加。报错 `no homophone for xxx` 时，在这里加一个同音同调、只有一个读音的常用字。

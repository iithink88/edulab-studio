# 写旁白脚本：episode.json + script.json

## episode.json

```json
{
  "title": "铜与稀硝酸：氧化还原配平与计算",
  "output_name": "铜与稀硝酸_Copper_and_Nitric_Acid",
  "pop_scenes": ["balance", "reduced"]
}
```
- `title`：写进 mp4 元数据。
- `output_name`：输出 `WS/<output_name>.mp4` 和 `.srt`。格式 `中文短名_English_Name`，不要有空格和 `/`。
- `pop_scenes`：这些幕里每句旁白开始时加一个轻"啵"音效（用在关键结论、列式计算幕）。幕切换的"嗖"音效是自动的。

## script.json 格式

```json
[
  {"scene": "intro", "lines": [
    {"zh": "19.2 g 铜加入足量稀硝酸，铜全部反应。",
     "tts": "十九点二克铜，加入足量稀硝酸，铜全部反应。",
     "en": "19.2 g of copper goes into excess dilute nitric acid and reacts completely."}
  ]},
  {"scene": "valence", "lines": [ ... ]}
]
```

| 字段 | 用途 | 规则 |
|---|---|---|
| `scene` | 幕 id | 英文标识符（`intro`、`figure`、`key`、`solve`、`check`、`outro`…），不重复；anim.js 必须有同名 `SC.<id>` 和 `TAGS.<id>` |
| `zh` | 中文字幕 | 正常化学写法：`HNO3`、`Cu(NO3)2`、`2SO2 + O2 ⇌ 2SO3`（元素符号或右括号后面的数字自动变下标，系数和小数不变）；离子电荷写 `Fe^{3+}`、`SO4^{2-}`、`e^-`；单位 `mol·L^{-1}`。可含读音标注，字幕里会自动去掉 |
| `tts` | 实际朗读的文本 | **只写能念的中文**（见下表）。省略时用 `zh` 朗读，所以 `zh` 里有数字或符号时必须写 `tts` |
| `en` | 英文字幕 | 意思对应即可，≤ 95 字符；同样可用 `_`、`^` |

**建议每句都写 `tts`**，哪怕和 zh 一样，这样不会漏。

## 幕的结构（标准 5~7 幕，按 chemistry-solving.md 的解题流程排）

| 幕 id（示例） | 内容 | 画面 |
|---|---|---|
| `intro` | 标题 + **逐条读题**：一句一个条件（足量 / 标况 / 体积要读出来），最后一句读"求什么" | 题目图片卡片，读到哪条框哪条 |
| `valence` / `equation` | 写对、配平方程式（氧化还原先标化合价） | 方程式条逐项写出，化合价数轴 |
| `balance` | 电子守恒定系数 → 原子守恒补全 | 电子分组、系数飞入、原子计数 |
| `bridge` | 双线桥 / 单线桥 | 桥线 + 电子流 |
| `mole` / `ice` | 以 n 为中心的计算；平衡题三段式 | 转化链 / 三段式表 / 分子盒 |
| `check`（推荐） | 守恒复查、限量判断、易错点 | 计数条、两堆分流 |
| `outro` | 方法回顾（步骤卡片）+ 报答案 + "下道题见！" | 卡片 → 吉祥物 + 答案气泡 |

## 写好旁白的规则

1. **一句一个点**，15~30 字最好；> 36 字宽（`--check` 会 warn）字幕就会折两行，折行后字幕框顶部升到 y≈860。
2. 口语化、像老师讲课：“来看这道题”、“为什么？”、“关键在于……”。化学题多用“先标化合价”“根据……守恒”“按系数比”。
3. 按画面顺序说：先说"看这条辅助线"，画面上才出现辅助线。
4. 数值要和解答完全一致；验算幕要真的代回去算。
5. 读题的句子要和题目原文对应，因为每句要对应一个高亮框。
6. 整个视频 1.5~3.5 分钟，大约 15~30 句。

## 化学式子的口语写法（tts 字段）

`--check` 会拦截 tts 里的阿拉伯数字和符号，化学式（`HNO3`、`SO2`）也算。**化学式一律换成中文名称**：

| 写法 | tts 里写 |
|---|---|
| `HNO3`、`H2SO4`、`HCl` | 硝酸、硫酸、盐酸（氯化氢） |
| `Cu(NO3)2`、`CuSO4·5H2O` | 硝酸铜、五水硫酸铜 |
| `SO2`、`SO3`、`NO`、`NO2`、`CO2`、`O2`、`H2O`、`NH3` | 二氧化硫、三氧化硫、一氧化氮、二氧化氮、二氧化碳、氧气、水、氨气 |
| `Fe^{3+}`、`Fe^{2+}`、`SO4^{2-}`、`OH^-`、`H^+` | 铁离子、亚铁离子、硫酸根离子、氢氧根离子、氢离子 |
| `2SO2 + O2 ⇌ 2SO3` | 二氧化硫和氧气反应生成三氧化硫（可逆）；需要读系数时：两分子二氧化硫…… |
| `3Cu + 8HNO3 = …` | 三个铜原子和八个硝酸分子……，或"铜配三，硝酸配八" |
| `+5`、`−2`、`0 价` | 正五价、负二价、零价 |
| `2e^-`、`3×2e^-` | 两个电子、三乘二个电子 |
| `19.2 g`、`64 g/mol` | 十九点二克、六十四克每摩尔 |
| `0.3 mol`、`0.2 mol·L^{-1}` | 零点三摩尔、零点二摩尔每升 |
| `0.2 mol·L^{-1}·min^{-1}` | 零点二摩尔每升每分钟 |
| `22.4 L/mol`、`4.48 L` | 二十二点四升每摩尔、四点四八升 |
| `N_A`、`6.02×10^{23}` | 阿伏加德罗常数、六点零二乘十的二十三次方 |
| `n(Cu)`、`c(SO2)`、`v(SO2)` | 铜的物质的量、二氧化硫的浓度、二氧化硫的反应速率 |
| `K`、`α`、`50%` | K（单个字母可以）、转化率、百分之五十 |
| `3 : 2`、`2 : 1 : 2` | 三比二、二比一比二 |
| `ΔH = −92 kJ/mol` | 焓变等于负九十二千焦每摩尔 |
| `pH = 7` | p H等于七 |
| 有机物 `CH3COOH`、`C2H5OH` | 乙酸（醋酸）、乙醇 |

提示：
- 名称比化学式好听也好懂，第一次出现说全称（"稀硝酸"），之后可简称（"硝酸"）。
- 单位一定要读出来，字幕 zh 里也写单位。
- 元素符号单独出现时读中文（"铜从零价升到正二价"），不要读 "C u"。

**断句**：GLM-TTS 没有停顿标记，能控制停顿的只有标点。
- 逗号放在念的时候自然换气的地方：长主语之后、"所以/因此/于是"之前、连等式的每个"等于"之前（`O B等于根号下二加一，等于根号三`）。
- 一个分句（两个标点之间）不超过 18 个字，否则 TTS 会自己找地方停，常常停在词中间；`--check` 会 warn。
- 逗号不要把一个名词拆开：不要写 `平面，P A D`、`角，O C B`。
- 冒号、分号也会产生停顿，只在真的要停的地方用。
- 小写字母单个可以（`t`、`x`），连续小写单词（sin、log、max）会被 warn，要换成中文。
- 年份、编号之类按习惯读："二〇二五年"。

## 写完后的自检
- [ ] 每句 `tts` 都没有数字和符号（`--check` 无 ERROR）
- [ ] intro 每一句对应题目图上的一个高亮框
- [ ] 最后的答案与第 1 步你自己算的（chem_check.py 验过方程式）一致，单位齐全
- [ ] tts 里没有化学式，全是中文名称
- [ ] outro 最后一句报出答案

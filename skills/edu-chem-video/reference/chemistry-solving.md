# 化学解题方法（第 1 步必读）

物理题讲"过程"（受力 → 运动），化学题讲"守恒与比例"：**一切计算都落在"物质的量"上，一切推理都靠"守恒"**。学生最常错的是：方程式没配平就算、系数比用成质量比、K 用了物质的量、被还原的量和参加反应的量混为一谈、忽略"足量/少量"。视频的幕结构照着下面的流程排。

## 一、标准五步（写进 storyboard.md 顶部的"解题卡"）

| 步 | 问自己 | 写下来 |
|---|---|---|
| 1. 审题定性 | 反应类型（复分解、氧化还原、可逆反应、电化学、有机）？"足量 / 少量 / 恰好 / 过量"指谁？状态（标况气体？溶液体积？） | 反应类型、限量物质、已知量及单位 |
| 2. 写对方程式 | 产物对不对（稀 / 浓硝酸、量的多少影响产物）？配平：观察法 → 原子守恒；氧化还原 → **电子守恒**定关键系数，再原子守恒补全；离子方程式再查**电荷守恒** | 配平好的方程式 + 用 `chem_check.py` 校验 |
| 3. 找关系 | 已知量和所求量之间的桥：系数比（= 物质的量之比）、守恒（原子 / 电子 / 电荷 / 质量）、关系式法（多步反应首尾相连）、差量法 | 一句话："n(X) : n(Y) = a : b" 或 "失电子总数 = 得电子总数" |
| 4. 以 n 为中心计算 | m ↔ n（M）、V(气，标况) ↔ n（22.4 L/mol）、c ↔ n（V 溶液）、N ↔ n（N_A）。平衡题用**三段式**（起始 / 转化 / 平衡），K、转化率、速率都从表里读 | 每一步的式子，单位带着走 |
| 5. 验算 | 守恒复查（原子、电子、电荷各一遍）、数量级（标况 22.4 L/mol 量级）、有效数字、答案是否符合题意（足量时以不足量为准） | 验算方式与结果 |

## 二、常用方法与"讲清楚"的关键点

| 方法 | 用在 | 视频里要讲出来的那一句 |
|---|---|---|
| 化合价升降 + 电子守恒 | 氧化还原配平、计算 | "失电子总数 = 得电子总数"：2 × 3 = 3 × 2，用最小公倍数定系数 |
| 双线桥 / 单线桥 | 表示电子转移 | 双线桥连**同种元素**（反应物 → 生成物），标"失去/得到 a × b e⁻"；单线桥从还原剂中失电子的元素指向氧化剂中得电子的元素，只标总数 |
| 原子守恒 | 配平补全、多步计算 | 某元素在反应前后的总原子数不变（N：3×2 + 2 = 8） |
| 电荷守恒 | 离子方程式、溶液中离子浓度 | 阳离子正电荷总数 = 阴离子负电荷总数 |
| 三段式 | 化学平衡、速率、转化率 | 转化量之比 = 系数比；平衡 = 起始 ∓ 转化；K 用**平衡浓度** |
| 关系式法 | 多步反应（工业流程、滴定） | 首尾物质的物质的量之比，中间产物消掉 |
| 差量法 | 固体质量变化、气体体积变化 | 质量差 / 体积差与反应物的量成正比 |
| 区分作用 | 硝酸、浓硫酸等既作氧化剂又显酸性 | 8 个 HNO₃ 里 2 个被还原、6 个显酸性：被还原的 n = 生成 NO 的 n |
| 限量判断 | "足量 / 少量" | 先比较 n / 系数，小的那个是限量物质，计算以它为准 |

## 三、用 `scripts/chem_check.py` 验算（必做，零依赖）

```bash
PY SKILL/scripts/chem_check.py balance "Cu + HNO3 -> Cu(NO3)2 + NO + H2O"     # 求系数 + 原子/电荷核对 + 摩尔质量
PY SKILL/scripts/chem_check.py check   "3Cu + 8HNO3 = 3Cu(NO3)2 + 2NO + 4H2O" # 核对你写的方程式（不平衡退出码 1）
PY SKILL/scripts/chem_check.py balance "MnO4^- + Fe^{2+} + H^+ -> Mn^{2+} + Fe^{3+} + H2O"   # 离子方程式
PY SKILL/scripts/chem_check.py mass "CuSO4·5H2O"                                # 摩尔质量（课本相对原子质量）
```
- 相对原子质量用题目给的；没给时脚本用课本常用值（Cl 35.5、Cu 64……）。
- 化合价与电子转移脚本不算（需要化学判断），手算后用 "失 = 得" 与系数核对。
- 数值计算（三段式、K、转化率、溶液配制）自己列式，再用 python 算一遍；anim.js 常量区写**同样的式子**（`const N_NO = N_CU * 2 / 3`），画面与答案同源。

## 四、把解变成画面（化学题的特殊要求）

1. **方程式条是主角**：配平好的方程式常驻顶部，后面每一幕都从方程式取数据（系数飞出去成为比例、三段式的转化量；物质 glow 表示"现在说它"）。
2. **守恒要"数"出来**：原子守恒用 `tally()` 计数条，左右相等打 ✓；电子守恒用两排电子按组增长到相等。
3. **比例要"飞"出来**：系数从方程式飞到表格 / 转化箭头上（`flyText`），而不是凭空写出。
4. **微观要对得上宏观**：分子盒里每个分子代表固定的量（如 0.5 mol），转化时按系数比消失 / 出现，数量和三段式一致。
5. **单位贯穿**：每个数都带单位（板书、字幕、节点），K 的单位可省略但要说明用的是浓度。

## 五、常见题型 → 幕结构建议

| 题型 | 幕（scene id） | 核心画面 |
|---|---|---|
| 氧化还原配平 + 计算（template） | intro → valence → balance → bridge → mole → reduced → outro | 化合价数轴、电子分组增长、系数飞入、原子计数、双线桥电子流、转化链 |
| 化学平衡 / 速率（examples/equilibrium） | intro → ice → rate → kc → conv → outro | 分子盒按比例转化、三段式逐行填、c-t 曲线、浓度代入 K、转化率条 |
| 物质的量综合计算 | intro → equation → map（以 n 为中心）→ solve → check | `molMap` 高亮换算路径，数值计数 |
| 离子反应 / 离子方程式 | intro → ions（拆成离子）→ cancel（删去旁观离子）→ check（电荷守恒） | 烧杯里的离子 token，旁观离子淡出，电荷计数 |
| 电化学（原电池 / 电解池） | intro → device → electrodes（正负极反应）→ flow（电子、离子移动）→ calc | 装置图、电子沿导线移动、阴阳离子向两极迁移 |
| 溶液配制 / 滴定 | intro → relation（关系式）→ calc → error（误差分析） | 烧杯 / 滴定管液面、滴定曲线（`graph`） |
| 工业流程 | intro → flow（流程图逐框亮起）→ key step → calc | 流程框 + 箭头，物质 token 沿流程移动 |

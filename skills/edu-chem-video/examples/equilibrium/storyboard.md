# 分镜 Storyboard — 化学平衡三段式（示例）

## 解题卡
- 反应：2SO₂(g) + O₂(g) ⇌ 2SO₃(g)，恒容 V = 2 L，5 min 达平衡。`chem_check.py check "2SO2 + O2 = 2SO3"` ✓
- 三段式（mol）：起始 4 / 2 / 0；转化 2 / 1 / 2（按系数比 2:1:2，由 SO₃ 生成 2 mol 推出）；平衡 2 / 1 / 2。
- (1) v(SO₂) = (2 mol ÷ 2 L) ÷ 5 min = 0.2 mol·L⁻¹·min⁻¹
- (2) 平衡浓度 1 / 0.5 / 1 mol·L⁻¹；K = 1² / (1² × 0.5) = 2（L·mol⁻¹）
- (3) α(SO₂) = 2 / 4 = 50%
- 验算：O 原子守恒 4×2 + 2×2 = 12 = 2×2 + 1×2 + 2×3 ✓；易错点：K 用了物质的量而不是浓度。

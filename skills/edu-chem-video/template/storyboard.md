# 分镜 Storyboard

每句旁白一行。`句` 列必须是 `幕id 句号`（从 0 数），与 script.json 一一对应（`build_audio.py --check` 会核对）。
- **指**：这句提到的元素如何被点亮（方程式里的物质 glow、hiBox），其余是否变淡。
- **动**：这句里画面上发生的**一个**体现化学推理的动作（见 reference/visual-design.md 动作表）。第一幕和最后一幕可写"—"。
- **留**：动作结束后留下的标记（化合价、系数、双线桥、表格数值）。
- **板书**：右侧石板写什么。

## 解题卡（第 1 步的结果）
- 反应类型：氧化还原（Cu 被稀硝酸氧化）。变价元素：Cu 0 → +2（升 2，失 2e⁻）；N +5 → +2（降 3，得 3e⁻），只有生成 NO 的那部分 N 变价。
- 配平：电子守恒 2 × 3 = 3 × 2 = 6 ⇒ Cu、Cu(NO₃)₂ 配 3，NO 配 2；N 原子守恒 3×2 + 2 = 8 ⇒ HNO₃ 配 8；H 守恒 ⇒ H₂O 配 4；O 检验 24 = 24。
  `chem_check.py balance "Cu + HNO3 -> Cu(NO3)2 + NO + H2O"` → [3, 8, 3, 2, 4] ✓
- 计算：n(Cu) = 19.2 / 64 = 0.3 mol；n(NO) = 0.3 × 2/3 = 0.2 mol；V = 0.2 × 22.4 = 4.48 L；
  被还原 HNO₃ = n(NO) = 0.2 mol（N 守恒）；共消耗 HNO₃ = 0.3 × 2 + 0.2 = 0.8 mol。
- 验算：电子守恒 0.3 × 2 = 0.2 × 3 = 0.6 mol e⁻ ✓。易错点：把 8 mol HNO₃ 全当成被还原。

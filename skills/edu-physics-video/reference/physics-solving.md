# 物理解题方法（第 1 步必读）

讲解视频的质量上限 = 你的解题质量。数学题"算对就行"，物理题还要**讲清楚模型和过程**：学生最常错的不是计算，是研究对象选错、受力漏画、过程没分段、方向没定。视频的幕结构就照着下面的解题流程排。

## 一、标准六步（写进 storyboard.md 顶部的"解题卡"）

| 步 | 问自己 | 写下来 |
|---|---|---|
| 1. 审题建模 | 研究对象是谁（单体 / 整体 / 隔离）？理想化条件（光滑、足够长、轻绳、质点、小角度）？ | 对象、模型名（斜面、传送带、板块、弹簧、圆周、平抛、带电粒子在场中、平行玻璃砖……） |
| 2. 过程分段 | 运动 / 状态在哪里发生突变（速度为零、共速、离开、碰撞、进出场、摩擦力方向改变）？ | 阶段列表 ①②③，每段的起止条件 |
| 3. 受力 / 状态分析 | 每一段：重力 → 弹力（接触面）→ 摩擦力（按相对运动方向）→ 其他力（电场、磁场、拉力）；光学：入射点、法线、界面 | 每段一张受力图（力的大小、方向），状态量 |
| 4. 选规律 | 求加速度 / 时间 → 牛顿定律 + 运动学；只关心初末状态 → 动能定理 / 机械能守恒；碰撞、爆炸、反冲 → 动量守恒；圆周 → 向心力方程；光 → 折射定律 + 几何 | 每段用哪条规律（一句话理由） |
| 5. 列式求解 | 规定正方向；每段一组方程；分段处用衔接量（末速度 = 下一段初速度） | 方程与数值，**符号解先于数值** |
| 6. 验算 | 量纲、极限（μ→0、θ→0、n₂→n₁）、数量级、另一种规律再算一遍（能量 ↔ 动力学） | 验算方式与结果 |

**分段判据要讲出来**（这是视频最有价值的地方）：
- "能否滑回？"比较 mg sinθ 与最大静摩擦 μmg cosθ（通常取最大静摩擦 ≈ 滑动摩擦）。
- "何时共速？"传送带 / 板块：共速后要重新判断是一起运动还是相对滑动。
- "是否脱离？"圆周最高点比较所需向心力与 mg；接触面弹力 N = 0 是临界。
- "是否全反射？"入射角与临界角比较。
- 摩擦力方向：看**相对**运动（或相对运动趋势）的方向，不是看速度方向。运动反向 ⇒ 摩擦力反向。

## 二、用 sympy 验算（强烈建议，尤其是多段过程）

默认 `python3` 可能缺包，用 `setup_check.sh` 报告的 PY 或装有 sympy 的解释器。把解题卡里的方程写成脚本，数值答案、分段时刻、临界条件都由它给出，再抄进 anim.js 的常量区：

```python
from sympy import *
g, th, mu, v0 = 10, Rational(3, 5), Rational(1, 2), 10   # 用课本近似：sin37°=3/5, cos37°=4/5
s, c = th, Rational(4, 5)
a1 = g*s + mu*g*c;  t1 = v0/a1;  x = v0**2/(2*a1)
a2 = g*s - mu*g*c;  v = sqrt(2*a2*x);  t2 = v/a2
print(a1, t1, x, a2, v, t2)       # 10 1 5 2 2*sqrt(5) sqrt(5)
# 能量验算：½mv0² − f·2x = ½mv²
```

- 特殊角用课本近似值（37°/53° → 0.6/0.8），**anim.js 里也用同样的值**（`const SIN = 0.6, COS = 0.8`），不要 `Math.sin(37°)`，否则画面数值和答案对不上。
- 符号答案（如光学题 R = (n₂ − n₁) s l / [n₂ (d_A cos θ_A + d_B cos θ_B)]）用 sympy `simplify` 化简，并代一组数检验极限。

## 三、把解变成动画（物理题的特殊要求）

1. **运动必须按真实解析解走**：anim.js 顶部写出 `x(t)`、`v(t)`（分段函数，与 sympy 结果一致），画面用 `simT()` 把旁白时间**线性**映射到物理时间。可以慢放（屏幕上注明"慢放 ×0.2"），不能用缓动函数（eio）驱动物体位置——那会伪造加速度。
2. **图像与运动同步**：v-t / x-t 图的曲线只画到当前物理时间，游标跟着物体走；位移 = 面积时用 `graph().area()` 着色。
3. **力按比例画**：同一幕里力箭头长度 ∝ 大小（一个常量 `FS` px/N）。12 N 的箭头必须比 8 N 长 1.5 倍，观众才能"看出"谁大。速度箭头同理（`VS` px per m/s）。
4. **示意放大要声明**：小角度、小位移放大画时，角落写 `notToScale()`（"角度已放大"）。
5. **分段时刻要有画面事件**：速度为零时物体停一下、v 箭头消失；摩擦力反向时箭头绕作用点转 180°；共速时两个速度箭头合并。

## 四、常见题型 → 幕结构建议

| 题型 | 幕（scene id） | 核心画面 |
|---|---|---|
| 斜面 / 水平面往返（template） | intro → force → up → back → down → outro | 受力分解、合力首尾相接、真实减速/加速、v-t 两段、摩擦反向 |
| 传送带 | intro → model → phase1 → together（共速判断）→ phase2 → outro | 物块 + 皮带两套速度箭头、相对运动箭头、v-t 面积差 = 划痕 |
| 板块模型 | intro → force（隔离两物体）→ slip → common（共速）→ outro | 两个物体各自受力图（同一摩擦力等大反向）、相对位移 |
| 平抛 / 斜抛 | intro → split（分解）→ time → landing → outro | 频闪轨迹 `trail({dots})`、水平/竖直分速度箭头随时间变化 |
| 圆周运动 | intro → force → critical（临界）→ solve → outro | 向心力箭头指向圆心、最高点 N→0 的临界画面 |
| 能量 / 动量守恒 | intro → process → conserve → solve → check | `bars()` 能量柱 / 动量柱实时变化，总和不变 |
| 带电粒子在场中 | intro → field → trajectory → geometry（找圆心/半径）→ outro | `bField` / `eField`、洛伦兹力始终指向圆心、轨迹圆心作图 |
| 几何光学（examples/laser-curvature） | problem → setup → 每条定律一幕 → 几何关系 → outro | `ray` 光线传播、法线、角弧、"角度已放大" |

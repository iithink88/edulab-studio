# 写旁白脚本：episode.json + script.json

## episode.json

```json
{
  "title": "斜面上滑与返回：受力分析 + 牛顿第二定律",
  "output_name": "斜面往返_Block_on_an_Incline",
  "pop_scenes": ["up", "back"]
}
```
- `title`：写进 mp4 元数据。
- `output_name`：输出 `WS/<output_name>.mp4` 和 `.srt`。格式 `中文短名_English_Name`，不要有空格和 `/`。
- `pop_scenes`：这些幕里每句旁白开始时加一个轻"啵"音效（用在关键结论、列式计算幕）。幕切换的"嗖"音效是自动的。

## script.json 格式

```json
[
  {"scene": "intro", "lines": [
    {"zh": "质量 2 kg 的物块，以 10 m/s 从底端冲上斜面。",
     "tts": "质量两千克的物块，以十米每秒的速度，从底端冲上斜面。",
     "en": "A 2 kg block shoots up the slope from the bottom at 10 m/s."}
  ]},
  {"scene": "force", "lines": [ ... ]}
]
```

| 字段 | 用途 | 规则 |
|---|---|---|
| `scene` | 幕 id | 英文标识符（`intro`、`figure`、`key`、`solve`、`check`、`outro`…），不重复；anim.js 必须有同名 `SC.<id>` 和 `TAGS.<id>` |
| `zh` | 中文字幕 | 正常物理写法：`v_0 = 10 m/s`、`a_1`、`d_A`、`v^2`、`m/s^2`（`_x` 下标、`^x` 上标，一个字符；多个字符用 `_{max}`）。可含读音标注，字幕里会自动去掉 |
| `tts` | 实际朗读的文本 | **只写能念的中文**（见下表）。省略时用 `zh` 朗读，所以 `zh` 里有数字或符号时必须写 `tts` |
| `en` | 英文字幕 | 意思对应即可，≤ 95 字符；同样可用 `_`、`^` |

**建议每句都写 `tts`**，哪怕和 zh 一样，这样不会漏。

## 幕的结构（标准 5~7 幕，按 physics-solving.md 的解题流程排）

| 幕 id（示例） | 内容 | 画面 |
|---|---|---|
| `intro` | 标题 + **逐条读题**：一句一个条件，最后一句读"求什么" | 题目图片卡片，读到哪条框哪条，下方出条件小标签 |
| `force` / `model` / `setup` | 研究对象、模型、受力分析（一句一个力） | 左边装置图，力箭头逐个长出；右边板子写各力大小 |
| `up` / `phase1` / … | 每个运动阶段一幕：合力 → 加速度 → 运动学结果 | 物体按解析解真实运动，v-t 图同步 |
| `back` / `critical` | 分段判断、临界条件（能否滑回、是否共速、是否脱离） | 比较两个量（箭头叠放、柱状对比），方向变化的动画 |
| `check`（推荐） | 能量 / 另一方法验算、极限检验 | 图像面积、能量柱 |
| `outro` | 方法回顾（步骤卡片）+ 报答案 + "下道题见！" | 卡片 → 吉祥物 + 答案气泡 |

多问题：每问对应一个或几个阶段幕，板子用 `bbox` 写出"(1) …"答案框。

## 写好旁白的规则

1. **一句一个点**，15~30 字最好；> 36 字宽（`--check` 会 warn）字幕就会折两行，折行后字幕框顶部升到 y≈860。
2. 口语化、像老师讲课：“来看这道题”、“为什么？”、“关键在于……”。物理题多用“研究对象是……”“这一段……”“方向沿……”。
3. 按画面顺序说：先说"看这条辅助线"，画面上才出现辅助线。
4. 数值要和解答完全一致；验算幕要真的代回去算。
5. 读题的句子要和题目原文对应，因为每句要对应一个高亮框。
6. 整个视频 1.5~3.5 分钟，大约 15~30 句。

## 物理式子的口语写法（tts 字段）

`--check` 会拦截 tts 里的阿拉伯数字和符号。对照表：

| 写法 | tts 里写 |
|---|---|
| `F = 20 N` | F等于二十牛（或二十牛顿） |
| `10 m/s`、`2 m/s²`、`5 m`、`1 s` | 十米每秒、二米每二次方秒、五米、一秒 |
| `2 kg`、`500 g` | 两千克、五百克 |
| `3 J`、`6 W`、`2 A`、`4 V`、`5 Ω`、`1 T`、`2 C` | 三焦耳、六瓦、二安、四伏、五欧、一特斯拉、二库仑 |
| `3.0×10⁸ m/s`、`1.6×10⁻¹⁹ C` | 三乘十的八次方米每秒、一点六乘十的负十九次方库仑 |
| `37°` | 三十七度 |
| `v₀`、`v₁`、`a₂`、`d_A` | v零、v一、a二、dA |
| `v²`、`v₀²` | v的平方、v零的平方 |
| `½mv²` | 二分之一m v平方 |
| `x = v₀²/2a` | x等于，v零的平方除以二a |
| `mg sinθ`、`μmg cosθ` | 重力沿斜面的分力 / m g乘正弦西塔、动摩擦因数乘m g乘余弦西塔（不要写 sin/cos，会被逐个字母读） |
| `F合`、`f_max` | 合力、最大静摩擦力 |
| `ΔE`、`Δt` | 能量的变化量、时间间隔（或 德尔塔t） |
| `>`、`<`、`≈` | 大于、小于、约等于 |
| `2√5` | 二倍根号五 |
| 希腊字母 | 见 pronunciation.md 的希腊字母表（θ 西塔、μ 动摩擦因数 / 谬、φ 菲……） |
| `mg`、`qE`、`qvB` | 优先说物理名称（重力、电场力、洛伦兹力）；必须读字母时写 `m g`，pron.py 会逐个读 |

提示：
- 物理量第一次出现说名称，之后可以用字母：“动摩擦因数零点五”，而不是“μ等于零点五”。
- 单位一定要读出来（字幕 zh 里也写单位），这是物理和数学视频最明显的区别。

- 括号、分式很长时，拆成两句，或用逗号给 TTS 停顿："六十分之，六十减七t"。

**断句**：GLM-TTS 没有停顿标记，能控制停顿的只有标点。
- 逗号放在念的时候自然换气的地方：长主语之后、"所以/因此/于是"之前、连等式的每个"等于"之前（`O B等于根号下二加一，等于根号三`）。
- 一个分句（两个标点之间）不超过 18 个字，否则 TTS 会自己找地方停，常常停在词中间；`--check` 会 warn。
- 逗号不要把一个名词拆开：不要写 `平面，P A D`、`角，O C B`。
- 冒号、分号也会产生停顿，只在真的要停的地方用。
- 小写字母单个可以（`t`、`x`），连续小写单词（sin、log、max）会被 warn，要换成中文。
- 年份、编号之类按习惯读："二〇二五年"。

## 写完后的自检
- [ ] 每句 `tts` 都没有数字和符号（`--check` 无 ERROR）
- [ ] intro 每一句对应题目图上的一个高亮框
- [ ] 最后的答案与第 1 步你自己算的（sympy 验算过的）一致，单位齐全
- [ ] outro 最后一句报出答案

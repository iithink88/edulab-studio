# 讲解动画设计（写 storyboard.md 和 anim.js 之前必读）

## 目标：图会"讲题"，物理过程在画面上真的发生

差的做法：画好一张静态受力图，之后每句只多一个标签，推导全在右边板子上。`render.mjs motion` 会把这种句子标成 `STATIC` / `POP`。

好的做法：**每句旁白，图上都有一个动作把这句物理"演"出来**。说"重力分解"，就让两条投影虚线画出、两个分力从重心长出；说"摩擦力反向"，就让摩擦力箭头绕作用点转 180°；说"匀减速到零"，就让物块按 `x(t)` 真实地减速滑上去、停住，v-t 图同步画出来。板子只记结论。

## 每句旁白的四个动作：指 → 动 → 留 → 连

| | 做什么 | 怎么写 |
|---|---|---|
| **指** | 旁白提到哪个元素，它就被点亮；无关元素变淡 | `glow(pts, col, bump(lt, at(k, f)))`；次要的力 `forces(..., {a: 0.3})`；intro 用 `hiBox` |
| **动** | 一个体现物理/推理的动作，0.6~1.5 秒（运动过程可占整句） | 见下面的动作表 |
| **留** | 动作后留下的标记：力箭头、轨迹、尺寸线、角弧、数值 | `vec`、`trail`、`dimLine`、`arcMark`、`readout` |
| **连** | 板子上的式子与图上的量**同色** | 见下面的颜色约定 |

一句话只做**一个主要动作**。

## 颜色约定（整部视频不变）

| 颜色 | 含义 |
|---|---|
| 黄 `C.yellow` | 重力 mg、角度标注、强调、答案框 |
| 蓝 `C.blue` | 弹力 N、拉力 T、物体本身、玻璃 |
| 粉 `C.pink` | 摩擦力 f |
| 紫 `C.purple` | 分力、场（E、B） |
| 绿 `C.green` | 合力、加速度、最终结果 |
| 红 `C.red` | 速度、光线、轨迹 |
| 灰 `C.gray` | 标签、辅助线、投影线 |

## 动作表：物理 → 动画

| 物理 / 说法 | 图上的动作 | 代码 |
|---|---|---|
| 研究对象 | 物体弹出 + 荧光笔框一下 | `block(..., {p})` + `glow(corners, C.yellow, bump(...))` |
| 画某个力 | 箭头从作用点"长"出来，标签在箭头尖外侧弹出 | `vec(from, v, {p: P(at(k, f), 0.8)})` |
| 力的分解 | 投影虚线先画，两个分力再从作用点长出 | `components(from, v, axis, e, {labels})` |
| 平衡（N 与 mg cosθ） | 分力的复制品转 180° 滑到另一个力的位置 | `slideSeg(a, b, c, d, eio(P(...)))` |
| 合成（同一直线） | 一个力的复制品首尾相接滑到另一个力的末端，合力在旁边画出 | `slideSeg` + `vec(..., {c: C.green})` |
| 比较两个力的大小 | 小力的复制品叠到大力上，多出的一截荧光 | `slideSeg` + `glow` |
| 摩擦力方向 / 反向 | 先用 `flow` 箭头流显示相对运动方向，再画 f；反向时 f 绕作用点转 180° | `flow(pts, {c: C.red})`；`rotAbout(pts, from, PI * e)` |
| 牛顿第二定律 | 合力箭头旁边长出加速度箭头，a 的数值计数 | `vec(..., {label: \`a = ${countTo(0, a, e)}\`})` |
| 匀变速运动 | **物体按解析解真实运动**（可慢放），速度箭头随 v(t) 变长变短，计时器走 | `simT` + `sPos(t)` + `vec(front, v * VS)` + `clockTag` |
| 位移 / 最大距离 | 虚线轨迹跟随，最后画尺寸线 | `trail(pos, 0, t)` + `dimLine` |
| v-t / x-t 图 | 曲线只画到当前物理时间，游标跟随；位移 = 面积着色 | `graph()` → `.curve(f, 0, t)`、`.cursor(t, f)`、`.area(...)` |
| 平抛 / 频闪 | 小球按 x(t), y(t) 飞出，频闪点留下；分速度箭头随时间变 | `ball` + `trail(pos, 0, t, {dots: 0.1})` + `vec` |
| 能量转化 / 守恒 | 能量柱实时升降，总和那根不变 | `bars(x, y, h, [{label, v, c}], vmax)` |
| 动量守恒 / 碰撞 | 两物体按解真实运动、碰撞、分开；动量柱前后对比 | `block` + `bars` |
| 弹簧 | 弹簧随物体位置伸缩，弹力箭头长度 ∝ 形变 | `spring(a, b)` + `vec` |
| 圆周运动 | 物体沿圆运动，向心力箭头始终指向圆心 | `ellPts` + `along()` + `vec` |
| 光线传播 / 折射 | 光线沿路径画出（脉冲在光线上跑），法线虚线，i/r 角弧展开 | `ray(pts, p)`、`refractDir`、`arcMark` |
| 小角度近似 | 放大画出，角落注明 | `notToScale(p)` |
| 带电粒子在磁场 | 粒子沿圆弧运动，洛伦兹力箭头指向圆心，作两条半径找圆心 | `bField` + `vec` + `tech` |
| 代入数值 | 图上的数值飞进板子上的算式 | `flyText(str, from, blPos(row, dx), e)` |
| 答案 | 盖章 + 答案框 | `stamp`、`bbox` |

## 两个完整示例
- `template/`：斜面往返（受力分析 + 牛二 + 两段运动 + v-t 图）。力学题从这里改。
- `examples/laser-curvature/`：几何光学竞赛题（光线、平行玻璃砖侧移、折射定律小角近似、屏幕正视图分解、圆弧几何）。光学 / 几何味重的题读它。

## motion 检查查不出来、你必须自己守住的
- **物理正确性**：力的方向、大小比例、分段时刻、摩擦力方向，截图时逐项核对。画错方向比动画不好看严重得多。
- **运动不许伪造**：物体位置只能来自 `sPos(t)` 之类的解析解，用 `simT` 线性映射时间；`eio` 只用于"复制品滑动""箭头生长"这类讲解动作。
- **比例一致**：同一幕的力用同一个 `FS`，速度用同一个 `VS`。
- **图形清单**：题目里所有物体、接触面、已知量、所求量都要画出来。
- **标签不重叠**：`vec` 的标签放在箭头尖外侧；两个箭头尖太近时用 `lo` / `lside` 侧移，或缩短标签（数值写在板子上）。

## 常用写法

```js
// 物体按真实解运动：这句话的 5% 处出发，用这句 75% 的时长走完物理上的 T1 秒
const run = at(2, 0.05), win = S.dur(2) * 0.75;
const tp = simT(lt, run, win, T1);                       // 物理时间
const B = blockAt(tp);                                   // 位置来自 sPos(tp)
vec(front, vmul(G.up, vel(tp) * VS), { c: C.red, label: `v = ${vel(tp).toFixed(1)}` });
trail(t => midAt(t), 0, tp, { c: C.red });
VT.curve(vel, 0, tp); VT.cursor(tp, vel);
clockTag(560, 830, tp);
txt(`慢放 ×${(T1 / win).toFixed(2)}`, 150, 830, { size: 30, c: C.gray, al: 'left' });
```

## 版面与节奏
- 图形在左半边（x 60~900，y 130~860），板子在右边；物理示意图常常很宽，放不下就缩小比例或 `ctx.translate` 左移，不要压到板子上。
- 每幕开头承接上一幕结尾的状态（同一套几何函数，物体停在上一幕结束的位置）。
- 动作放在句子的 15%~80%；运动过程可以占满整句。

## storyboard.md（写 anim.js 之前必须先写）
格式见 `template/storyboard.md`：顶部先写**解题卡**（见 physics-solving.md）和**图形清单**，再每句一行 `| 幕id 句号 | 旁白要点 | 指 | 动 | 留 | 板书 |`。
- 除第一幕和最后一幕外，"动"必须填，且是动作表里的动作；只写"出现/显示/亮起/高亮"会被 `--check` 拒绝。
- 每幕至少一句是连续运动（物体运动、箭头旋转、复制品滑动、曲线生长、计数）。

`node render.mjs motion`：`STATIC` 必须改；每幕至少一句 `MOVE`。确实不需要动的句子列在 `episode.json` 的 `"static_ok": ["幕id 句号"]`，交付时说明理由。

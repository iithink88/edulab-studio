# 分镜 Storyboard — 激光测曲率（光学 · 竞赛题）

## 解题卡
- 研究对象：一束激光；过程：进入玻璃块折射 → 玻璃内传播 → 出射再折射（平行面 ⇒ 出射光平行入射光，只侧移）。
- 规律：平行玻璃砖侧移 d ≈ s·δ（小角度）；折射定律 n₁ sin i = n₂ sin r，小角 n₁ i = n₂ r；几何：切线 ⊥ 半径 ⇒ 两切线夹角 = 圆心角；R = l / φ。
- 关键点：光斑斜向偏移 = 法线既上倾又向纸外偏；**只有竖直分量 d cos θ 对应切线倾角**。
- 答案：(1) δ_A = d_A / s；(2) i_A = n₂ d_A / [(n₂ − n₁) s]；(3) φ = n₂ (d_A cos θ_A + d_B cos θ_B) / [(n₂ − n₁) s]，R = l / φ。
- 验算：n₂ → n₁ 时 i → ∞（玻璃不折光，测不出角度）✓；量纲：d/s 无量纲 ✓。
